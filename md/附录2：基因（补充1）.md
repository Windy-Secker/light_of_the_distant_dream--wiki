# 附录2：基因系统（补充1）

> **系统警告**：此系统为可选规则，对游戏体验与扮演方向影响较大。**使用前请务必征询所有参与者的意见**。基因选择为角色创建阶段行为，一经确定不可更改（除非剧情特殊事件允许）。

## 一、正面基因（新增）

### 1.1 社交/风格类

| 基因名     | 效果                                                                                                           | 备注 |
| ---------- | -------------------------------------------------------------------------------------------------------------- | ---- |
| **魅力**   | 发动「请」时检定获得**优势**；触发词中的“请”可替换为别的口癖（如“拜托”“求你了”等），**一次性更换**，不影响效果 | —    |
| **随性**   | 所有**非战斗检定**获得 **+1加值**                                                                              | —    |
| **抗压王** | **非战斗检定**不受劣势影响（即劣势被抵消为普通检定）                                                           | —    |
| **乐观**   | 在**优势检定**中额外获得 **+1加值**                                                                            | —    |

### 1.2 资源/分配类

| 基因名                | 效果                                |
| --------------------- | ----------------------------------- |
| **万事通 Lv.1/2**     | 初始可分配专精点数 **+1/+2**        |
| **三好学生 Lv.1/2/3** | 初始可分配基础属性点数 **+1/+2/+3** |

## 二、负面基因（新增）

### 2.1 社交/风格类

| 基因名   | 效果                                                         | 扮演提示                                                     |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **自闭** | 发动「请」时检定获得**劣势**；触发词固定为“请”，**不可更换** | 你不太擅长用语言影响别人，每次开口都担心说错话               |
| **刻板** | 所有**非战斗检定**获得 **-1减值**                            | 你做事一板一眼，严格按照流程来，稍微超出计划就不知所措       |
| **易垮** | **非战斗检定**中，劣势的影响加重（劣势时额外 -2）            | 你承受压力的能力比常人弱一些，一点点风吹草动就能让你心态崩盘 |
| **悲观** | 在**劣势检定**中额外承受 **-1减值**                          | 你总觉得事情会往坏的方向发展……而且通常你是对的               |

### 2.2 资源/分配类

| 基因名                  | 效果                                    | 扮演提示                                       |
| ----------------------- | --------------------------------------- | ---------------------------------------------- |
| **单科生 Lv.1/2**       | 初始可分配专精点数 **-1/-2**（最低为0） | 你只对特定领域感兴趣，其他方面几乎一窍不通     |
| **输在起跑线 Lv.1/2/3** | 初始可分配基础属性点数 **-1/-2/-3**     | 你从小就没有别人那种“天赋”，只能靠后天努力弥补 |

### 2.3 代价型

| 基因名     | 效果                                                                                 | 扮演提示                                             |
| ---------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| **双刃剑** | 所有检定**首次获得优势时额外+2**，但所有检定**首次获得劣势时额外-2**                 | 你做事总是走极端，要么大获全胜，要么一败涂地         |
| **易燃**   | 在优势检定中获得 **+2加值**；但劣势检定中额外承受 **-2减值**                         | 你的情绪就像汽油，一点火星就能点燃，但也极易燃烧殆尽 |
| **赌徒**   | 可主动将一次**普通检定**转为**劣势检定**；若成功，该次效果翻倍；若失败，承受双倍后果 | 你信奉“一无所有或者赢下所有”，没有中间选项           |
