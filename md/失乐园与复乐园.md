# 失乐园与复乐园

> **警告**：失乐园与复乐园的存在本身属于高度机密。新芽纪元绝大多数轮回者组织甚至不知道这两个名称。本章内容建议仅在剧情推进至相应阶段后逐步揭示。

## 🟢基础设定

> *以下内容为“传说”层级的信息——玩家可能在极其罕见的情况下听闻过某些碎片化的传闻，但几乎不可能确知其真伪。*

### 一、失乐园

在轮回者世界的边缘传说中，“失乐园”被描述为一个**不属于现世的地方**——一个藏匿在空间夹缝中的、前文明残存者的聚居地。

> 绝大多数轮回者将这些传说视为都市神话或古代寓言。即使是梦境裁判所的高级职员，也仅有极少数人知晓其真实性。

### 二、复乐园

与之相对的，“复乐园”则是失乐园分裂出去的另一个派系。在极少数情报报告中，复乐园被描述为与“神明降临”有关的危险组织，但目前尚无确凿证据证明其存在。

> 一些疑似复乐园成员的活动痕迹偶尔会在III级以上事件中被发现，但始终无法追踪到其源头。

## 🔴 深层设定

### 一、失乐园的本质

#### 1.1 定义

“失乐园”同时指代两件事物：

1. **一个独立符文结界内部的空间**——原初海德里斯孑遗者的聚居地
2. **这些幸存者所构成的组织本身**

> 该名称源于海德里斯残部的自我认知：他们自视为“被驱逐出‘乐园’（即旧世界）的人”。

#### 1.2 物理形态

失乐园**没有固定位置**，其本体是**一块藏在空间结构中的月球碎片**。在无瑕纪元末期的神战中，月球的一部分被堕神撕裂，海德里斯人将其捕获并藏入空间夹缝中，改造为可居住的符文结界空间。

> 这意味着失乐园的入口无法通过常规空间定位手段找到。只有知晓其空间坐标的人，或持有特定“钥匙”者才能进入。

#### 1.3 失乐园内部

经过数千年的繁衍，失乐园已经从一个避难所发展为一个**小型城邦**。其居民主要是：

- 最初跟随永生者进入的精英后裔（“乐园人”）
- 在无瑕纪元末期被“遴选”进入的少数幸存者

失乐园拥有独立的文明体系、语言（海德里斯语为官方语言）与社会结构。其技术水平在某些领域（尤其是符文技术）远超新芽纪元，但也存在明显的技术断层。

### 二、原罪与限制

#### 2.1 原罪

所有乐园人**生来背负着原罪**。这是他们作为“前文明残余”的客观代价。具体表现为：

> **一旦离开失乐园的范围，如果没有特殊手段屏蔽自身的存在，很快便会被混沌锁定甚至抹除。**

| 离开者的类型     | 后果                                     |
| ---------------- | ---------------------------------------- |
| 普通乐园人       | 数天内被混沌锁定位置，随后被抹消         |
| 永生者           | 数小时内被锁定（因其存在更为显著）       |
| 有特殊屏蔽手段者 | 可在外界活动有限时间，但屏蔽持续消耗愿力 |

#### 2.2 屏蔽手段

已知的屏蔽手段包括：

- **特定符文装置**（造价极高，难以量产）
- **定期进行“混沌伪装”术式**（需要专门训练的轮回者维持）
- **以强力愿力持续对抗混沌侵蚀**（仅限永生者级别）

> 这种“原罪”也是大多数乐园人不愿离开失乐园的主要原因——并非缺乏意愿，而是缺乏手段。

#### 2.3 困境

失乐园内部是安全的，但资源有限。乐园人群体若想生存下去，必须从外部获取某些资源，因此少数掌握屏蔽手段的“外勤人员”被派遣至新芽纪元的世界执行任务。

但悖论在于：这些外勤人员的活动本身就带有混沌污染的风险。因此失乐园对外界的干预极为谨慎，且通常以“隐藏身份”的方式间接进行。

### 三、失乐园的内部派系

失乐园并非铁板一块。在其漫长的历史中，形成了多个对“审判日”有不同解读的派系：

#### 3.1 抗争派

| 项目                 | 内容                                           |
| -------------------- | ---------------------------------------------- |
| **核心理念**         | 延续前文明对抗堕神的使命，帮助新文明渡过审判日 |
| **历史地位**         | 失乐园的主流派系，最初的主导者                 |
| **对审判日的态度**   | 必须阻止，主动行动                             |
| **对新芽纪元的态度** | 有义务引导与保护（尽管方式有争议）             |

抗争派是失乐园的创始派系。他们认为自己是前文明的火种，肩负着传承知识与对抗堕神的使命。在海德里斯残部中，此派系的历史最为悠久。

#### 3.2 自然派

| 项目                 | 内容                                         |
| -------------------- | -------------------------------------------- |
| **核心理念**         | 审判日是自然规律，人类幸存或毁灭都是客观结果 |
| **历史渊源**         | 与主流派系同样古老                           |
| **对审判日的态度**   | 顺其自然，不主动干预                         |
| **对新芽纪元的态度** | 旁观即可，干涉无意义                         |

自然派的形成时间与抗争派相差无几。他们认为：既然前文明没能阻挡审判日，再尝试一次也是徒劳。不如顺其自然，接受文明可能的终结。

> 自然派并非投降派。他们只是认为“抗争”本身没有意义，但不会主动帮助堕神。

#### 3.3 谎言派

| 项目                 | 内容                                     |
| -------------------- | ---------------------------------------- |
| **核心理念**         | 审判日是统治阶级编造的谎言，用于维持秩序 |
| **历史渊源**         | 后起的“新海德里斯人”（乐园人）中产生     |
| **对审判日的态度**   | 不存在，无需应对                         |
| **对新芽纪元的态度** | 没有特殊立场                             |

谎言派起源于若干代之后出生的乐园人。他们从未亲眼见过神战，也未曾经历审判日。在他们看来，所有关于“审判日”的记载都是掌权者为了维稳而制造的叙事。

> 谎言派的观点在失乐园的后辈世代中有一定市场，但在经历过神战的永生者眼中，这种说法无异于否认历史。

### 四、复乐园的诞生

#### 4.1 降临派的形成

在失乐园漫长的历史中，一部分永生者逐渐偏离了最初的信念。他们开始认为：

- 对抗堕神是没有胜算的
- 与其等待毁灭，不如接受并利用堕神的力量
- 精英应当先于大众获得“被赦免”的权利

这部分人被称为**降临派**。他们相信“神明”必将降临，而聪明人应当成为“被选中”的那一方。

#### 4.2 分裂（约200年前）

大约**200年前**，降临派与抗争派的矛盾激化至不可调和的程度。失乐园内战爆发。

内战的结果：

- 降临派夺走了失乐园 **1/5的面积**（即整个符文结界空间的五分之一）
- 他们独立出去，建立了自己的聚居地，并改称为**复乐园**
- 失乐园与复乐园之间自此处于分裂状态

> 复乐园的名称含义是“重新建立的乐园”——他们宣称自己才是海德里斯的正统继承者。

#### 4.3 复乐园的理念

复乐园继承了降临派的核心理念：**接纳神明的降临，精致利己，社会达尔文主义**。他们认为：

- 审判日不可阻挡，但精英可以通过与堕神“协商”获得豁免
- 新芽纪元的人类只是“材料”，用于完成向神明清算的过渡
- 永生者应当追求自身的永恒，而非为注定毁灭的文明殉葬

> 复乐园是当前纪元中“倒悬之塔”等事件的幕后推手。其成员定期在新芽纪元的世界活动，布置术式以收割生命力与灵魂能量。

### 五、永生者的分布

无瑕纪元末期，共有 **22位** 永生者进入失乐园。至今：

| 状态   | 人数            |
| ------ | --------------- |
| 已逝世 | 7人（各种原因） |
| 在世   | 15人            |

**在世永生者的派系分布：**

| 派系                   | 人数 |
| ---------------------- | ---- |
| 抗争派                 | 10人 |
| 自然派                 | 2人  |
| 降临派（已加入复乐园） | 3人  |

> 原降临派在失乐园内战前为5人，其中2人在内战中死亡，余下3人随复乐园独立出走。
>
> 永生者的“寿命”并非无限。虽然远超凡人，但漫长的岁月中仍可能因愿力消耗、混沌侵蚀、战斗损伤或精神崩溃而死亡。7位逝世的永生者中，多数是在神战后最初的数百年间逝去的。

### 六、失乐园的技术

#### 6.1 符文技术

失乐园保存着无瑕纪元时期的部分符文知识，包括：

- 原初符文阵法的完整构造方案
- 部分禁忌符文的原始观想路径
- 关于基耶夏韦（轮回巨构）的较完整记录

> 但并非所有知识都完好无损。在长达数千年的传承中，部分知识因保管不当或传承中断而丢失或失真。

#### 6.2 混沌屏蔽技术

失乐园最核心的实用技术是**混沌屏蔽技术**，这是一种使乐园人能够在外界活动而不被混沌锁定的手段。

- 抗争派掌握最成熟的版本（用于外勤人员）
- 复乐园据信也发展出了自己的版本
- 自然派可能也掌握了一部分技术，但使用频率极低

#### 6.3 空间结界技术

失乐园本身就是一个巨大的空间结界。其维持需要消耗大量愿力，而愿力的主要来源是**基耶夏韦回流的纯净灵魂能量**。这意味着失乐园的存续，在某种意义上依赖于基耶夏韦的正常运转。

### 七、失乐园与外部世界的关系

#### 7.1 与梦境裁判所

| 项目       | 内容                                             |
| ---------- | ------------------------------------------------ |
| **抗争派** | 极有限度的间接接触（通过高阶档案），但不直接行动 |
| **自然派** | 几乎不接触外界                                   |
| **复乐园** | 敌对（裁判所将其列为疑似敌意组织）               |

梦境裁判所的高层可能知晓失乐园的存在，但双方并无正式外交关系。失乐园的抗争派偶尔会通过“加密档案”或“匿名情报”的方式，向裁判所传递某些关键信息，但从不暴露自己的真实身份。

#### 7.2 与蔷薇学会

蔷薇学会与失乐园的关系更为间接。学会的创立者在历史上发掘的“海德里斯遗产”，很可能就是抗争派在无瑕纪元末期刻意埋下的。从这个意义上说，蔷薇学会是**失乐园抗争派的一条“长线”**。

> 蔷薇学会的现任高层（包括会长亚伯拉罕·史密斯）并不一定知晓这一层关系。失乐园的布局往往跨越数个世纪，信息在传递中可能已经脱离了原始计划。

#### 7.3 复乐园的活动

复乐园的外勤人员活跃于新芽纪元的世界，其活动包括：

- 布置生命力收割术式（如“倒悬之塔”）
- 招募愿力水平高的个体（作为“容器”）
- 收集关于新纪元符文技术的情报
- 尝试提前触发审判日（加速“与神明协商”的进程）

> 复乐园是目前梦境裁判所面对的最棘手的潜在威胁之一。
