# 第三章：战斗规则（v0.1）

---

## 一、战斗基础概念

### 1.1 战斗中的两种行动类型

| 行动类型     | 说明                               | 每回合限制 |
| ------------ | ---------------------------------- | ---------- |
| **标准行动** | 攻击、施放符文、使用物品、全力防御 | 每回合1次  |
| **快速行动** | 移动、切换符文、拔取武器、简短交流 | 每回合1次  |

> 每回合角色可执行 **1个标准行动 + 1个快速行动**。

### 1.2 距离范围

战斗采用**抽象距离**，不依赖精确方格：

| 距离等级 | 描述             | 示例                             |
| -------- | ---------------- | -------------------------------- |
| **贴身** | 近身格斗距离     | 拳脚、匕首攻击                   |
| **近距** | 同一房间/区域内  | 投掷、短兵器冲刺、短程符文       |
| **中距** | 隔着一段开阔空间 | 枪械、远程符文、大部分能量系符文 |
| **远距** | 跨越较大空间     | 狙击、远距离追踪符文             |

> 移动一个距离等级消耗 **快速行动**。超过一个等级的移动（如从近距到远距）可能需要额外的回合或消耗体力池。

## 二、战斗流程

### 2.1 战斗轮结构

每个**战斗轮**分为两个阶段：

1. **选择阶段**：所有可行动的目标**同时选择**本回合要执行的行动（标准行动 + 快速行动）
2. **结算阶段**：按照行动的先后顺序依次结算所有行动

在所有目标完成结算后，开始下一个战斗轮。

### 2.2 行动顺序判定

行动先后由以下因素共同决定，按优先级从高到低排列：

| 优先级 | 决定因素           | 说明                                                   |
| ------ | ------------------ | ------------------------------------------------------ |
| 1      | **无法行动的惩罚** | 被偷袭、眩晕等状态导致目标在本轮无法行动，自动排在最后 |
| 2      | **状态影响**       | 某些状态（如束缚、恐惧）可能导致行动顺序延后（GM裁定） |
| 3      | **体魄属性**       | 体魄越高，行动顺序越靠前                               |
| 4      | **特定符文/专精**  | 某些符文或专精可提供先手优势                           |

> **基础规则**：在无特殊状态影响时，按 **体魄值从高到低** 决定行动顺序。体魄相同则同时行动。

### 2.3 战斗轮流程图

```
【战斗轮开始】
     ↓
【选择阶段】所有目标同时选择本回合行动
     ↓
【排序阶段】按优先级确定行动顺序
     ↓
【结算阶段】按顺序依次结算行动
     ↓
【战斗轮结束】→ 进入下一战斗轮
```

### 2.4 战斗开始流程

1. **先攻判定**：若战斗从常规对峙开始，所有参战者进行 **先攻检定：D20 + 体魄调整值**
2. **排序**：按先攻检定结果从高到低排定行动顺序（仅首轮使用，之后按2.2规则动态调整）
3. **第一轮**：按排序进入第一个战斗轮

## 三、偷袭规则

### 3.1 偷袭判定

当一方在未被察觉的情况下发动攻击时，视为**偷袭**：

- 偷袭方需进行 **潜行专精检定**（DC = 被偷袭方体魄调整值 + 10）
- 若成功，偷袭成立
- 若失败，被偷袭方察觉攻击，进入常规战斗流程

### 3.2 偷袭轮

偷袭成功时，战斗流程变为：

1. **偷袭轮**：偷袭方获得一个**额外战斗轮**
   - 被偷袭方在本轮中**不可行动**
   - 偷袭方可正常执行行动（攻击、施法等）
   - 偷袭方本轮的攻击**无法被闪避或格挡**（但仍可被被动物理抗性减免）
2. **常规战斗开始**：偷袭轮结束后，按正常流程进入第一个战斗轮，所有目标恢复行动能力

### 3.3 偷袭示例

> **场景**：赵子涵（潜行专精3级）试图偷袭一名巡逻的敌人。

- 赵子涵进行潜行检定：**D20 + 体魄调整值(+1) + 潜行专精(+3)** = 17
- 敌人体魄调整值为 +1，DC = 11
- 17 ≥ 11 → 偷袭成功
- **偷袭轮**：赵子涵获得一次额外行动机会，敌人不可行动
- 赵子涵使用「混沌枷锁」攻击 → 命中，敌人被束缚
- 进入常规战斗轮，敌人因束缚状态行动顺序延后

## 四、攻击与伤害

### 4.1 攻击检定

> **攻击检定 = D20 + 相关属性调整值 + 专精等级（如适用）**

| 攻击类型 | 检定公式                                       |
| -------- | ---------------------------------------------- |
| 符文攻击 | D20 + 算力调整值 + 符文熟练度（若有）          |
| 物理攻击 | D20 + 体魄调整值 + 格斗专精等级                |
| 远程武器 | D20 + 体魄调整值 + 追踪/潜行专精等级（GM裁定） |

### 4.2 难度等级（防御方）

| 防御方式           | DC                                 |
| ------------------ | ---------------------------------- |
| 未做防御的普通目标 | 10                                 |
| 有基本防备的目标   | 12                                 |
| 主动闪避的目标     | 目标体魄调整值 + 12 + 专精（潜行） |
| 使用防御符文的目标 | 符文提供的防御值                   |
| 偷袭状态下         | 无法闪避/格挡（仅可被动减免）      |

### 4.3 伤害类型与计算

#### 伤害类型总览

| 伤害类型     | 来源                         | 作用对象        | 减免方式                   |
| ------------ | ---------------------------- | --------------- | -------------------------- |
| **物理伤害** | 武器、徒手、物质系符文       | 肉体            | 物理抗性                   |
| **符文伤害** | 能量系、空间系等直接能量冲击 | 肉体 + 符文结构 | 系别抗性 / 符文屏障        |
| **灵魂伤害** | 意识系、因果系、时间系       | 灵魂印记        | 特殊防护符文               |
| **混沌伤害** | 混沌浓度侵蚀、混沌造物       | 肉体 + 灵魂     | 无常规减免                 |
| **解构伤害** | 解构系符文瓦解符文结构       | 符文术式 / 屏障 | 不可减免；通过算力检定抵抗 |

#### 符文攻击伤害公式

> **基础伤害 + （投入愿力单位数）× 每单位伤害**

| 符文             | 基础伤害    | 每额外1愿力 |
| ---------------- | ----------- | ----------- |
| 业火（完整）     | 1d6（灵魂） | +1d4        |
| 能量冲击（基础） | 1d4（符文） | +1          |

> 投入愿力不能超过角色当前愿力上限与单回合最大投入限制（通常不超过10点/回合）。

#### 物理攻击伤害公式

> **武器基础伤害 + 体魄调整值**

| 武器类型     | 基础伤害 |
| ------------ | -------- |
| 徒手         | 1d2      |
| 轻型武器     | 1d4      |
| 中型武器     | 1d6      |
| 重型武器     | 1d8      |
| 枪械（近距） | 2d4      |
| 枪械（中距） | 2d6      |

### 4.4 伤害减免完整规则

| 伤害类型 | 减免方式               | 计算顺序                               |
| -------- | ---------------------- | -------------------------------------- |
| 物理     | 物理抗性               | 最终伤害 - 物理抗性                    |
| 符文     | 系别抗性（如有）       | 最终伤害 - 系别抗性（最小为1）         |
| 灵魂     | 特殊防护符文           | 如有「灵魂壁垒」则全额吸收至屏障HP归零 |
| 混沌     | 无减免                 | 直接生效                               |
| 解构     | 不可减免，通过检定抵抗 | 算力检定抵抗（见5.3）                  |

## 五、符文系谱与战斗交互

### 5.1 系谱速查

| 系谱 | 核心特征                             | 主要伤害类型                     |
| ---- | ------------------------------------ | -------------------------------- |
| 物质 | 操纵实体物质：土、金属、水流、风     | 物理                             |
| 能量 | 操纵纯能量：光、电、热、冲击         | 符文                             |
| 空间 | 操纵空间结构：传送、扭曲、结界       | 符文 / 解构（切割）              |
| 生命 | 操纵生命本身：治疗、感知、操控生物   | 符文（毒性） / 灵魂（汲取）      |
| 意识 | 操纵心智与灵魂：念力、幻术、灵魂攻击 | 灵魂                             |
| 因果 | 操纵可能性：命运、概率扭曲           | 灵魂 / 解构                      |
| 时间 | 操纵时间流：加速、减速、预知         | 灵魂（老化） / 符文（断层）      |
| 解构 | **瓦解符文结构，构造的反面**         | **解构**（不直接造成生命值伤害） |

### 5.2 相生关系

当同时激活或连续使用**相生符文**时：

- **效果增强**：伤害/效果获得 **+2** 加值
- **消耗降低**：第二个相生符文的愿力消耗减少 **1点**（最低为1）

| 相生关系  |
| --------- |
| 物质-能量 |
| 能量-生命 |
| 空间-解构 |
| 因果-解构 |

### 5.3 相克关系

当攻击符文的系谱 **克制** 目标的防御/体质系谱时：

- **攻击检定**获得 **优势**（roll两次取高）
- 若攻击命中，伤害 **+1d4**

当攻击符文的系谱 **被克制** 时：

- **攻击检定**获得 **劣势**（roll两次取低）
- 若攻击命中，伤害 **-1d4**（最低为1）

> 若攻击/被攻击符文的系谱互相克制，从左到右依次按照算力消耗/愿力消耗/先攻顺序/1D10的大小判定克制关系

| 系谱 | 克制                   | 被克制                 |
| ---- | ---------------------- | ---------------------- |
| 物质 | 生命                   | 能量、空间、解构       |
| 能量 | 物质、生命             | 空间、生命、意识、解构 |
| 空间 | 物质、能量、解构       | 因果、解构             |
| 生命 | 能量、意识             | 物质、能量、时间、解构 |
| 意识 | 能量                   | 生命、因果、解构       |
| 因果 | 空间、意识、时间、解构 | 解构                   |
| 时间 | 生命、解构             | 因果                   |
| 解构 | **除时间外**           | 时间、空间、因果       |

### 5.4 解构

**核心定位**：解构是构造的反面，专精于破坏其它符文使用者的符文术式。

**解构攻击效果**：

| 目标状态           | 解构效果                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------- |
| **正在维持符文**   | 被攻击者必须通过 **算力检定（DC = 10 + 攻击者算力调整值）** ，失败则该符文立即失效，且无法在1回合内重新激活 |
| **存在符文屏障**   | 解构伤害直接作用于屏障，**每点解构伤害相当于 2点 屏障伤害**                                                 |
| **无任何符文效果** | 解构攻击对目标无直接效果（但可解析其结构）                                                                  |

**解构解析（非攻击用途）**：

- 标准行动：对正在使用符文的敌人进行解析
- 检定：**D20 + 算力调整值 + 神秘学专精等级**（DC = 10 + 对方符文等级）
- 成功：获知对方符文的 **系谱、消耗、可能弱点**
- 大成功（检定值 ≥ DC+5）：获知对方符文下次使用的 **时机与目标**

## 六、防御手段

### 6.1 主动防御选项

| 防御方式     | 消耗            | 效果                                   |
| ------------ | --------------- | -------------------------------------- |
| **被动防御** | 无              | 使用物理抗性减免物理伤害               |
| **主动闪避** | 快速行动        | 本回合物理/符文攻击命中DC + 体魄调整值 |
| **防御符文** | 标准行动 + 愿力 | 按符文效果提供屏障/护盾                |
| **全力防御** | 标准行动        | 本回合所有防御检定 +5，不可攻击        |

### 6.2 屏障与护盾

- 屏障有独立的 **屏障HP**
- 屏障HP归零时破碎，溢出伤害继续作用于角色
- 一般情况下同时只能维持 **1个主动屏障**

### 6.3 针对不同伤害类型的防御策略

| 伤害类型 | 推荐防御手段                            |
| -------- | --------------------------------------- |
| 物理     | 提升体魄、穿戴护甲、物质系屏障          |
| 符文     | 系别防护、空间偏转、高算力稳定符文结构  |
| 灵魂     | 意识系防护符文（如「灵魂壁垒」）        |
| 混沌     | 因果系符文封印、远离高浓度区域          |
| 解构     | 时间系加速/减速、空间系偏转、因果系预判 |

## 七、常见状态效果

| 状态     | 效果                            | 持续时间 | 解除方式              |
| -------- | ------------------------------- | -------- | --------------------- |
| **眩晕** | 下一回合失去标准行动            | 1回合    | 自动解除              |
| **流血** | 每回合开始失去 1d4 HP（可叠加） | 3回合    | 急救检定DC12          |
| **束缚** | 无法移动，攻击检定劣势          | 直到挣脱 | 标准行动+体魄检定DC15 |
| **燃烧** | 每回合失去 1d6 HP               | 2回合    | 水/扑灭动作           |
| **恐惧** | 攻击检定劣势，可选择远离施术者  | 1回合    | 自动解除              |
| **混乱** | 每回合行动由GM随机决定          | 1回合    | 自动解除              |
| **振奋** | 下一攻击检定优势                | 1次攻击  | 使用后消耗            |
| **标记** | 被标记目标受特定符文伤害+2      | 3回合    | 自动解除              |
| **虚弱** | 物理攻击伤害-2                  | 2回合    | 自动解除              |

## 八、特殊战斗规则

### 8.1 混沌浓度

在混沌浓度较高的区域战斗时：

| 浓度等级    | 检定DC | 失败后果                      |
| ----------- | ------ | ----------------------------- |
| 1级（轻微） | 12     | 1d4 灵魂伤害                  |
| 2级（中度） | 15     | 1d6 灵魂伤害                  |
| 3级（重度） | 18     | 2d4 灵魂伤害 + 符文消耗愿力+1 |

> 混沌浓度每回合结束对所有在场角色生效。检定公式：**D20 + 算力调整值**。混沌可通过特殊符文或仪式封印。

### 8.2 识质共鸣

当角色处于与自身识质高度契合的情境时：

- **共鸣**：该情境下所有符文攻击伤害 +2，或防御获得 +2 加值
- **反噬**：若角色强行违背自身识质行动，所有检定获得 -2 减值

## 九、完整战斗流程速查表

| 阶段       | 步骤       | 说明                                       |
| ---------- | ---------- | ------------------------------------------ |
| **战前**   | 偷袭判定   | 若成立 → 进入偷袭轮；若失败 → 进入常规战斗 |
| **偷袭轮** | 偷袭方行动 | 目标不可行动，无法闪避/格挡                |
| **战斗轮** | 选择阶段   | 所有目标同时选择行动                       |
|            | 排序阶段   | 按状态影响 → 体魄高低 → 符文/专精 决定顺序 |
|            | 结算阶段   | 按顺序依次结算所有行动                     |
| **循环**   | 重复       | 直到一方失去战斗能力、投降或逃离           |
