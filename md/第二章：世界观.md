# 第二章：世界观设定集(beta)

## 基础设定

> *以下内容为所有玩家创建角色与参与游戏前应了解的基础世界观信息。*

### 一、世界的基本法则

#### 1.1 愿力与观察者效应

人类的大脑是一种特殊的感觉器官，能够产生一种名为**识觉**的感知能力，即所谓的“第六感”。识觉使智慧生物能够感受到他人的情绪，以及一些无法通过常规五感获取的信息。

当智慧生物**意识到自己正在观察世界**时，观察行为本身即可改变被观察的对象。这种通过观察扭曲现实的力量，被称为**愿力**。

> 愿力水平与认知水平正相关：经历越丰富、越精彩的人，其愿力水平越高。

#### 1.2 愿力主导情绪：识质

愿力并非中性力量，它总是带着使用者的**情绪底色**。这种底色被称为**识质**。

- **暖色系识质**：与正面情绪相关（守护、希望、信念、喜悦）
- **冷色系识质**：与负面情绪相关（绝望、孤独、愤怒、恐惧）

识质决定了角色学习某些符文的倾向，并可作为扮演方向的指引。

#### 1.3 符文的本质

**符文是客观存在的**——它们是这个世界“规则”的具象化片段，而非人类发明的工具。只要完成观想，任何满足条件的轮回者都可以使用已掌握的符文。

符文的使用受两个核心因素制约：

- **算力**：天生决定，决定能同时使用多高级、多少个符文
- **愿力**：后天成长，决定能使用多少次符文、每次投入多强

### 二、轮回者与觉醒

#### 2.1 轮回者的定义

能够主动使用愿力的个体被称为**轮回者**。

绝大多数人类无法成为轮回者，他们的识觉处于被抑制的状态。能完成觉醒的人始终是少数。

#### 2.2 轮回与灵魂印记

普通人类的灵魂印记在肉体死亡后会自行消散。而**轮回者的灵魂印记不会消散**——它会坠入地心深处的某个神秘巨构中，在某个时刻重新诞生于世。

这意味着轮回者拥有“重来一次”的可能。但这个过程的具体机制，即使在轮回者内部也鲜有人知。

#### 2.3 觉醒的契机

觉醒通常与**极端的情绪体验**相关，尤其是极端的负面情绪。失去至亲、直面死亡、经历毁灭性的打击，这些时刻都有可能成为轮回者觉醒的触发点。

> 因此，冷色系识质的轮回者在总人口中占比显著高于暖色系。

### 三、梦境裁判所

#### 3.1 组织概况

梦境裁判所是处理与愿力、符文、轮回者相关事务的官方机构。总部共有九层：

| 层级      | 功能                                                 |
| --------- | ---------------------------------------------------- |
| 1~6层     | 常规行政部门                                         |
| **第7层** | 特殊行动部门（包括特别行动科、处决科、秘密保护科等） |
| **第8层** | 1号记忆库，存放记忆体与记忆档案                      |
| **第9层** | 最高指挥层，所有最高指令由此发出                     |

#### 3.2 特别行动科

第七层的核心科室之一，由刘思明担任科长。该科室负责处理常规部门无法解决的Ⅲ级以上事件。

特别行动科的科员可直接调用高等级记忆档案，并在出勤状态下拥有**不受总部审批限制的自主行动权**。

#### 3.3 记忆档案

梦境裁判所最核心的资源是**记忆体**——以符文技术保存的人类记忆片段。每份记忆档案按内容与敏感度分级：

| 等级 | 内容                           |
| ---- | ------------------------------ |
| Ⅰ~Ⅱ  | 常规事件记录                   |
| Ⅲ    | 涉及轮回者能力与伤亡的事件     |
| Ⅳ    | 涉及高等级符文或组织机密的事件 |
| Ⅴ    | 仅限最高权限调用的绝密记录     |

> 大多数Ⅴ级记录的内容，即使在裁判所内部也只有极少数人知晓。

### 四、混沌

#### 4.1 混沌的本质

符文的本质是**等价交换**。使用愿力扭曲现实，必然要支付相应的代价。当支付的代价不足以抵消扭曲的程度时，**混沌**便从永恒的规则中浮现。

混沌不是某种“邪恶力量”，而是客观规律的具现化产物——它只为抹消一切不被规则允许的扭曲而存在。

#### 4.2 混沌的污染

长期接触混沌或在高混沌浓度区域活动，可能导致**混沌污染**。受污染者可能出现：

- 感官紊乱
- 记忆模糊
- 情绪失控
- 符文失控
- 在极端情况下，被污染者可能转化为**混沌造物**

#### 4.3 混沌浓度等级

| 等级        | 描述                         |
| ----------- | ---------------------------- |
| 1级（轻微） | 轻微感官干扰，可自行恢复     |
| 2级（中度） | 可能触发混沌事件，需要干预   |
| 3级（重度） | 混沌造物可能出现，须立即处理 |

### 五、轮回者组织

#### 5.1 已知组织

| 组织             | 性质         | 描述                                                   |
| ---------------- | ------------ | ------------------------------------------------------ |
| **梦境裁判所**   | 官方机构     | 处理轮回者事务的官方组织，拥有最完善的符文档案库       |
| **蔷薇学会**     | 独立学术组织 | 专注于符文研究与历史考据的学者团体，与裁判所有合作关系 |
| **混沌导引学派** | 专门组织     | 专门研究混沌现象并探索抑制方法的组织，行事较为隐秘     |

#### 5.2 其它派系

还有一些不为大众所知的派系存在于世界上，它们的活动范围更隐蔽，目标也更难以捉摸。已知的存在包括一些自称为前文明后裔的团体，以及某些信奉“神明归来”的秘密结社。

### 一、审判日

#### 1.1 审判日的真相

> **建议揭示时机**：当玩家首次接触Ⅳ级及以上事件时，或遭遇与堕神相关的线索时。

**审判日**并非宗教概念中的“末日审判”，而是指**堕神完全降临并展露全部力量的时刻**。

堕神不会凭空降临。当人类的混沌积累到某个临界阈值时，堕神便自混沌中降生。祂们并非人格化的“神”，而是：

- 客观规律的代行者
- 只为湮灭“不被允许的扭曲”而行动的本能
- 不会因人类的意志而改变方向

每位堕神对应一种特定类型的扭曲。当某种扭曲在文明尺度上积累到不可接受的程度时，对应的堕神便会显现。

#### 1.2 审判日的可预测性

堕神的行动并非完全不可预测。事实上，审判日是一个**可以被精确推算甚至人为触发**的时间节点。这也是梦境裁判所一类组织努力研究混沌与符文体系的原因之一——他们试图在审判日降临前找到对抗的方法。

#### 1.3 奇迹与审判日

**奇迹符文**与堕神有着千丝万缕的联系。每一件奇迹的诞生，往往伴随着某种“不该发生的事情发生了”——这种异常的因果扭曲，既是奇迹诞生的土壤，也是吸引堕神目光的诱饵。

> 这意味着，奇迹既是人类对抗审判日的希望，也是可能提前引发审判日的隐患。

### 二、海德里斯与复乐园

#### 2.1 海德里斯的真相

> **建议揭示时机**：当玩家接触到海拉鲁相关事件，或首次遭遇自称“永生者”的个体时。

**海德里斯**——意为“太阳的后裔”——是前文明的孑遗。在上一轮文明毁灭时，少量幸存者以特殊手段延续了生命与知识，试图将对抗堕神的经验传递给后人。

这些**永生者**并非不死之身，而是通过技术手段维持了远超正常人类寿命的存在。他们大致分为两个派系：

| 派系       | 核心理念                                       |
| ---------- | ---------------------------------------------- |
| **抗争派** | 延续前文明对抗堕神的使命，帮助新文明渡过审判日 |
| **复乐园** | 接纳神明的降临，追求精致利己与社会达尔文主义   |

#### 2.2 永生者的技术路径

维持永生的技术有两种主要路径：

1. **生命力转移**：将他人的生命力转化到自己体内，延续生物性生命
2. **混沌同化**：将自身部分存在与混沌同化，维持在正常生物与混沌造物之间的临界状态

两种技术各有优劣。然而，无论哪种路径，长期维持永生都需要持续的代价——这导致部分永生者在漫长的岁月中逐渐偏离了最初的信念。

#### 2.3 失乐园

海德里斯残部的主要聚居地是一个名为**失乐园**的大型符文结界。除了海德里斯残部内部派系之外，失乐园中还生活着大量海德里斯后裔，他们与新人类之间存在某种程度的种族隔离。

> 失乐园的位置与内部结构，即使在裁判所的高层档案中也仅有模糊的记录。

### 三、奇迹符文的深层设定

> **建议揭示时机**：当玩家获得或接触奇迹符文相关信息时，逐步揭示。

#### 3.1 奇迹的共同性质

所有奇迹符文共享以下特征：

1. **总是以灵魂记忆的形式出现**——无法通过常规观想学习
2. **只能由一人继承**——奇迹有“选择宿主”的倾向，继承者死后奇迹才会转移到下一人
3. **无法解析，无法刻录，无法脱离灵魂发动**——奇迹与持有者的灵魂深度绑定

#### 3.2 已知奇迹

| 奇迹名   | 系谱   | 核心能力                   |
| -------- | ------ | -------------------------- |
| 虚构观想 | 因果系 | 瞬间解析并构造任意常规符文 |
| 定界幻灭 | 解构系 | 摧毁范围内所有符文定界     |

#### 3.3 奇迹的代价

奇迹的力量从不免费。除了各奇迹的特定副作用外，所有奇迹持有者都面临一个共同的风险：**奇迹本身会吸引堕神的注意**。使用奇迹，相当于在地图上点亮了自己的坐标。

### 四、混沌与堕神的深层机制

> **建议揭示时机**：当玩家深入到涉及混沌造物或高浓度混沌事件的剧情时。

#### 4.1 混沌造物的诞生

当混沌浓度突破某个临界点，且该区域的扭曲无法被自然消解时，**混沌造物**便可能诞生。混沌造物是混沌的具象化——它们没有灵魂，遵循的本能是“消除扭曲”或“扩散混沌”，具体形态由其诞生时周围的扭曲类型决定。

#### 4.2 混沌造物示例：大灰狼

雨竹村事件中的“大灰狼”便是一个典型的混沌造物。它诞生于雨竹村千年积累的混沌中，以“猎食灵魂”的方式履行其消除扭曲的本能。由于它与雨竹村的愿器体系深度绑定，最终通过仪式代偿（以替代物封印）的方式将其重新封印。

#### 4.3 堕神的层级

并非所有堕神都同等强大。堕神的力量与对应扭曲的积累程度成正比，文明尺度上的重大扭曲会催生更强的堕神。历史上有记载的堕神降临事件中，有的仅影响了一座城市，有的则毁灭了整个文明。

#### 4.4 地心巨构

轮回者灵魂不灭的机制与地心深处的某个神秘巨构有关。该巨构的体量与功能远超任何已知符文结界的规模——它是前文明留下的遗产，还是更古老的存在，无人确知。
