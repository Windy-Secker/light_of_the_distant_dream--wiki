# 符文库（新增补充）

以下为新增符文条目，按系谱分类排列。原有符文不再重复。

\##  一、物质系

\*\*核心特征\*\*：操纵实体物质——土、金属、水流、风、物理结构等。主要造成物理伤害。

| 符文名 | 算力消耗 | 基础效果简述 |

|--------|----------|--------------|

| \*\*湮灭之光\*\* | 28 | 将目标物质完全转化为光能，造成高额物理伤害 |

| \*\*失谐\*\* | 16 | 使目标物质结构的固有频率发生偏移，导致结构解体 |

| \*\*绝对刚体\*\* | 14 | 使物质在短时间内获得不可变形的绝对刚性 |

| \*\*骨质疏松\*\* | 12 | 使指定目标的“骨架”物理性质临时变脆 |

| \*\*理想镜面\*\* | 18 | 领域：区域内所有物体表面失去摩擦力 |

| 符文名 | 算力消耗 | 基础效果简述 |

| \*\*银锋\*\* | 16 | 凝聚空间裂隙为锋刃，斩断目标 |

| \*\*锁定\*\* | 12 | 以空间坐标锁定目标，使其无法移动/传送 |

| \*\*死线\*\* | 22 | 在空间中划出一道不可逾越的“死亡边界” |

| \*\*压缩\*\* | 18 | 将指定区域的空间进行压缩，对内部物体造成伤害 |
