# 第四章：探索与成长

冒险不仅仅是战斗。在任务之间、在旅途之中、在与世界的每一次交互里，角色都在成长。本章涵盖从日常探索到长期发展的所有规则。

## 一、专精技能详解

### 1.1 专精技能的行为覆盖

以下是各项专精技能涉及的行为类型、典型检定场景，以及可能获得提升的条件。

### 1.2 专精提升的额外方式

除上述条件外，专精技能还可通过以下方式获得提升：

| 方式         | 说明                                           | 获得进度               |
| ------------ | ---------------------------------------------- | ---------------------- |
| **导师指导** | 接受更高等级专精者的系统性指导                 | 每2天+1点（上限+3）    |
| **实践积累** | 在冒险中频繁使用某项专精技能（GM酌情决定）     | 每完成一次相关挑战+2点 |
| **理论学习** | 阅读专业书籍或进行系统训练（需在有条件时进行） | 每5天+1点（上限+2）    |
| **经历突破** | 在关键时刻因成功完成高难度挑战而顿悟           | 一次性+2点             |

> 专精等级提升进度采用与空闲时间相同的进度积累机制（见第四章第三节），而不是直接提升对应等级。

## 二、脱战状态下的自然恢复

### 2.1 生命值恢复

| 休息时长               | 恢复量              | 条件                         |
| ---------------------- | ------------------- | ---------------------------- |
| **短休息（1小时）**    | 体魄调整值（最低1） | 在安全区域，不进行剧烈活动   |
| **长休息（8小时）**    | 体魄 × 2 + 10       | 完全休息、睡眠               |
| **全天休整（24小时）** | 体魄 × 4 + 20       | 位于安全据点，完全不执行任务 |

> **快速恢复**：可选择在长休息期间不恢复而是额外消耗体力池，每消耗**10点**使生命值恢复量 **+5**。

### 2.2 体力池恢复

| 休息时长               | 恢复量                           | 条件                         |
| ---------------------- | -------------------------------- | ---------------------------- |

| **全天休整（24小时）** | 体力池上限的 **3/4**（向下取整） | 位于安全据点，完全不执行任务 |

## 三、事件完成后的愿力提升

### 3.1 核心规则

**愿力水平与经历正相关**。每完成一个事件，角色的愿力上限都可能获得提升，因为经历本身就在拓展认知的边界。

### 3.2 任务类事件

| 任务等级      | 完成度   | 基础提升 |
| ------------- | -------- | -------- |
| **Ⅰ级**       | 一般完成 | 1点      |
| **Ⅰ级**       | 完美完成 | 2点      |
| **Ⅱ级**       | 一般完成 | 2点      |
| **Ⅱ级**       | 完美完成 | 3点      |
| **Ⅲ级**       | 一般完成 | 3点      |
| **Ⅲ级**       | 完美完成 | 4点      |
| **Ⅳ级及以上** | 一般完成 | 4点      |
| **Ⅳ级及以上** | 完美完成 | 4~5点    |

> **完成度判定**：
>
> - 失败：未达成核心目标
> - 一般完成：达成了核心目标，可能有部分次要目标未完成，损失较严重
> - 完美完成：达成全部核心与次要目标，未造成可避免的额外损失
> - 特别的，若本次任务玩家角色出现减员，其余人愿力提升量-2

### 3.3 非任务事件

非任务事件包括：角色间的情感互动、个人线进展、重要发现、成长契机等。

| 事件类型         | 愿力提升 | 触发条件                              |
| ---------------- | -------- | ------------------------------------- |
| **情感深度交流** | 1~2点    | 与重要NPC或其他PC进行了触及灵魂的对话 |
| **个人线突破**   | 1~3点    | 完成了与角色源动力相关的关键节点      |
| **直面恐惧**     | 1~2点    | 在非任务情境中直面并克服了自己的恐惧  |
| **重大发现**     | 1~2点    | 发现了关于世界、历史或自身的隐藏真相  |
| **失去与哀悼**   | 1~2点    | 经历重要之人的离去并妥善处理了哀伤    |
| **和解与救赎**   | 1~3点    | 与过去的自己或他人达成和解            |

> GM应**酌情授予**非任务事件的愿力提升，原则上**不超过任务类事件的提升量**。非任务事件的点数可以在事件结束后立即结算，也可以合并到任务结束后一并结算。

### 3.4 愿力提升的特殊限制

| 限制                     | 说明                                       |
| ------------------------ | ------------------------------------------ |
| **同一事件不可重复结算** | 每个事件仅结算一次愿力提升                 |
| **情感事件不宜频繁**     | 过度使用非任务事件获取点数会稀释其叙事意义 |
| **上限无关**             | 愿力提升是**永久性**的，直接增加愿力上限   |

## 四、任务之间的空闲时间

在两次任务之间，角色可根据各自的时间安排在以下三项活动中选择：**提升体魄**、**提升专精**、**观想新符文**。

### 4.1 体魄提升（线性成长）

- 每积累 **14天** 提升 **1点** 体魄
- 进度**跨任务保留**（如已积累7天，下段空闲时间继续积累满14天即可完成提升）
- 可在空闲时间的任意天数中分配

| 投入天数 | 获得进度 | 进度累计 | 结果              |
| -------- | -------- | -------- | ----------------- |
| 1天      | +1天     | 不足14天 | 进度保留          |
| 14天     | +14天    | 达成     | 体魄 +1，进度归零 |
| 28天     | +28天    | 达成两次 | 体魄 +2           |

> 体魄上限为20，达到上限后无法继续提升。

### 4.2 专精提升（概率成长）

每天随机积累 **1~4点** 进度。当前进度 ÷ 10 = 目标等级时完成提升。

| 当前等级 | 所需进度 | 期望天数   |
| -------- | -------- | ---------- |
| 0 → 1    | 10点     | 约 3~10天  |
| 1 → 2    | 20点     | 约 5~20天  |
| 2 → 3    | 30点     | 约 8~30天  |
| 3 → 4    | 40点     | 约 10~40天 |
| 4 → 5    | 50点     | 约 13~50天 |

**具体规则：**

- 每天进行 **1次 1d4** 投掷，作为当日积累的进度
- 进度达到目标值（等级×10）时，**专精等级+1**，进度减去目标值（如积累至12点，目标为10点，则升1级后剩余2点进入下一级）
- 进度**跨任务保留**

**每日进度示例：**

| 日数  | 骰点 | 累计进度 | 状态                                 |
| ----- | ---- | -------- | ------------------------------------ |
| 第1天 | 3    | 3/10     | 进行中                               |
| 第2天 | 2    | 5/10     | 进行中                               |
| 第3天 | 4    | 9/10     | 进行中                               |
| 第4天 | 3    | 12/10    | **完成！** 等级+1，剩余2点计入下一级 |

**影响因素（GM可调整）：**

| 条件       | 每日骰子修正   |
| ---------- | -------------- |
| 有导师指导 | +1d2（额外骰） |
| 资源充足   | 优势           |
| 环境艰苦   | 劣势           |

### 4.3 观想新符文

观想符文需要**一次性完成**。如果中途被任务打断，下次空闲时进度减半（向下取整）。

#### 观想时间计算

| 符文平均算力消耗 | 基础观想天数 |
| ---------------- | ------------ |
| ≤10              | 7天          |
| 11~18            | 14天         |
| 19~24            | 21天         |
| 25~30            | 30天         |
| 31+              | 40天         |

**计算公式：**

> **最终观想天数 = （基础天数² ÷ 算力系数 - 识质匹配 - 导师指导）×独立系数**（向上取整）

其中：

- **识质匹配**：若角色的识质与该符文系谱的常用识质匹配，-2天
- **导师指导**：若有已掌握该符文的导师指导，-3天
- **独立系数**：某些符文具有的特殊修正值

#### 进度规则

| 情况                   | 进度处理                             |
| ---------------------- | ------------------------------------ |
| **成功完成观想**       | 符文加入可用符文列表                 |
| **任务打断**           | 进度减半（向下取整），下次空闲时继续 |
| **主动放弃**           | 进度归零                             |
| **观想失败（GM裁定）** | 损失 1d6 愿力，进度归零              |

**进度打断示例：**

> 角色正在观想一个需要14天的符文。已完成9天，任务开始，中断。下次空闲时，观想进度为 9÷2 = 4.5 → **4天**，还需10天完成。

### 4.4 空闲时间选择总结

| 选择           | 机制                              | 进度保留             | 适合情况                   |
| -------------- | --------------------------------- | -------------------- | -------------------------- |
| **提升体魄**   | 线性积累，14天=1点                | 跨任务保留           | 需要提高生存能力或物理输出 |
| **提升专精**   | 概率成长，每日1d4点，目标=等级×10 | 跨任务保留，溢出保留 | 希望特化某一技能           |
| **观想新符文** | 固定天数，须一次性完成            | 中断时减半           | 希望获得新的战斗或战术选项 |

## 五、特殊情况下的点数提升

除标准规则外，角色在冒险中可能因特殊事件获得额外的成长机会。若无特殊说明，**该条目下的每种情况对每个角色最多只会生效一次**。

### 5.1 奇遇

| 情况             | 可获得奖励                                       | 条件                       |
| ---------------- | ------------------------------------------------ | -------------------------- |
| **经历生死考验** | 体魄 +1 / 物理抗性 +1                            | 在战斗中濒死（HP≤0）后幸存 |
| **禁忌的知识**   | 愿力 +2 / 神秘学 +1（同时立刻受到 1d4 混沌伤害） | 接触了危险性极高的知识     |

### 5.2 情感羁绊

| 情况             | 可获得奖励                   | 条件                             |
| ---------------- | ---------------------------- | -------------------------------- |
| **拯救重要之人** | 愿力 +2                      | 在任务中优先救援了重要NPC或队友  |
| **建立深刻羁绊** | 专精：话术 +1 或 察言观色 +1 | 与NPC或队友达成了深度的情感连接  |
| **自我牺牲**     | 体魄 +1 或 愿力 +3           | 主动承担危险以保护他人（GM裁定） |

### 5.3 角色成长里程碑

| 里程碑                       | 奖励                                  |
| ---------------------------- | ------------------------------------- |
| **完成个人线核心目标**       | 愿力 +3 + 可选一个专精 +1             |
| **识质转变（重大心境变化）** | 愿力 +2，且识质描述可更新             |
