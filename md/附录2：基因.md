# 附录2：基因

> **警告**：此系统为可选规则，对游戏体验与扮演方向影响较大。**使用前请务必征询所有参与者的意见**。本系统旨在为角色创建增加额外维度与个性化选项，而非强制平衡性调整。

## 一、概述

因某些合乎情理或不可名状的原因，部分人体内含有特殊的基因片段。这些基因片段可能来自血脉传承、外部干涉，或某些无法追溯的源头。

基因可能带来增益，也可能带来负担，或二者兼有。无论效果如何，它们都可能为你的人生轨迹带来不可预知的变数。

## 二、基础规则

### 2.1 获取规则

- 每个玩家角色可拥有 **至多2个非负面基因**
- 负面基因 **不计入上述限制**（即可拥有2个正面/中性基因 + 任意数量的负面基因）
- 基因选择在**角色创建阶段**完成

### 2.2 交互规则

- 若基因效果提供基础属性加成，其加成**直接计入初始属性分配**（先加基础属性，再分配30点）
- 若基因效果提供初始专精点数，该加成**视为额外分配**（不占用初始6点）
- 所有基因效果**不可叠加**（同名基因不可重复选择）

### 2.3 禁用建议

- **不建议多个玩家同时持有奇迹相关基因**（如「远梦之光」）
- 基因「真·轮回者」的灵魂记忆符文，**GM可限制选择范围**（通常限制在III级及以下符文）

## 四、负面基因

> *以下基因可能会为冒险带来意想不到的阻碍，但也可能催生更深刻的故事。*

### 4.1 属性削弱类

| 基因名       | 效果                                                 | 扮演提示                                         |
| ------------ | ---------------------------------------------------- | ------------------------------------------------ |
| **脆弱**     | 初始体魄 -2（最低为3），物理抗性**减半**（向下取整） | 你比常人更容易受伤，一个轻微的撞击就可能让你倒下 |
| **呆滞**     | 初始算力 -2（最低为3），调查类检定**劣势**           | 你总是反应慢半拍，需要更多时间才能理解眼前的情况 |
| **麻木**     | 初始愿力 -2（最低为3），愿力恢复速度**减半**         | 你很难被任何事情真正触动，情绪像隔着一层磨砂玻璃 |
| **四体不勤** | 初始体魄 -1，初始算力 -1，初始愿力 +1                | 书没读好，活也没干好——但你感觉挺敏锐的           |
