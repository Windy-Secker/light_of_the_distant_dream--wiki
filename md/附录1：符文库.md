# 附录1：符文库

---

## 如何阅读符文库

本章按**系谱分类**整理所有可用符文。每个系谱以**简要索引表**开头，方便快速查阅；每个符文条目下方附带**完整详细说明**，包含具体的判定标准与数值规则。

### 符文详细条目的字段说明

| 字段             | 说明                                            |
| ---------------- | ----------------------------------------------- |
| **学名**         | 符文的标准名称                                  |
| **系谱分类**     | 所属的八个系谱之一                              |
| **平均算力消耗** | 维持该符文所需占用的算力值。**奇迹标注为「—」** |
| **伤害类型**     | 物理/符文/灵魂/混沌/解构 / 无（非攻击型）       |
| **基础效果**     | 符文的核心功能                                  |
| **愿力投入效果** | 每额外投入**10**点愿力的具体增幅                |
| **判定标准**     | 使用该符文时需要进行的检定公式与DC              |
| **特殊规则**     | 独有的限制、副作用或附加条件                    |
| **适用场景**     | 战斗/侦查/社交/生存等                           |

### 常规符文 vs 奇迹

- **常规符文**：具有明确的平均算力消耗，可被学习和观想，满足条件即可使用
- **奇迹**：算力消耗标注为「—」，不计入常规算力消耗；具有共同性质:
  1. 一定会作为灵魂记忆出现

  2. 同时只能由一人继承

  3. 无法解析/刻录/脱离灵魂发动

| **嬗变** | 20       | 将一种物质转化为另一种物质（同质量）   |

## 三、空间系

**核心特征**：操纵空间结构——传送、扭曲、结界、屏障。主要造成符文伤害或解构伤害。

| 符文名       | 算力消耗 | 基础效果简述                             |
| ------------ | -------- | ---------------------------------------- |
| **绝对立场** | 20       | 选定区域免疫所有伤害类型，持续有限时间   |
| **传送**     | 22       | 将施术者或接触目标瞬间移动到视线内的位置 |
| **茧**       | 12       | 以符文丝线包裹目标，形成封印/保护屏障    |
