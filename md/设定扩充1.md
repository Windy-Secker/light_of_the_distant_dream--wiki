# 梦境裁判所组织详章/基耶夏韦相关设定

---

## 🟢 第一层：基础组织架构

### 一、组织总述

#### 1.1 定位与职能

**梦境裁判所**是负责处理轮回者相关事务的官方机构，其职能类比于各国公安机关，但管辖范围仅限于轮回者之间的违法犯罪行为。

> 普通人类的刑事案件仍由各国常规执法机构处理；但当案件涉及愿力、符文或轮回者时，裁判所拥有优先管辖权。

#### 1.2 管辖范围

梦境裁判所的活动范围覆盖**亚洲及大洋洲地区**。世界其他地区由对应的轮回者管理机构负责。

#### 1.3 名称由来

“梦境裁判所”的名称源自其制式符文——**「梦境推演」**。通过将海德里斯分阶为δ+的「梦境推演」降至γ级，裁判所实现了该符文的制式化，使其可被大量职员同时使用。该符文的"复现场景-梦境干涉"特性，构成了裁判所调查与审判工作的技术基础。

### 二、总部与地表设施

#### 2.1 地表掩护层

梦境裁判所的总部位于**曙川市**地下，地表部分由一整片伪装成正常生活区的设施构成。这些地表的建筑包括：

- 小卖部、便利店
- 宾馆、旅店
- 住宅小区
- 餐馆、咖啡厅

这些设施看起来与正常城市无异，但其从业人员绝大多数为裁判所职工。地表区域的作用有两个：

1. **提供掩护**：使裁判所的活动不被普通民众察觉
2. **休整轮换**：每隔一段时间，地下职工与地表职工进行轮换，一部分人到地表休假，另一部分人回到地下继续工作

> 地表轮换机制确保了裁判所职工的心理健康，同时也有效掩盖了地下总部的真实规模。

#### 2.2 地下总部结构

总部主体位于地下，共分**九层**。各层功能如下：

| 层级      | 名称       | 功能                             |
| --------- | ---------- | -------------------------------- |
| **1~6层** | 常规办公区 | 各类科室的办公、行政、档案与后勤 |
| **第7层** | 特殊行动区 | 四个特殊科室驻地（详见2.3）      |
| **第8层** | 1号记忆库  | 存放记忆体与记忆档案             |
| **第9层** | 最高指挥层 | 所有最高指令的发布中心           |

> 地下总部各层之间通过严格的权限系统隔离。常规职员无权进入第7层及以上区域。

#### 2.3 第七层：特殊行动区

第七层是整个总部中专精度最高的区域。该层面积不大，常驻人员不超过**20人**。共设四个科室：

| 科室名称       | 核心职能                         | 常驻人数 |
| -------------- | -------------------------------- | -------- |
| **特别行动科** | 处理III级以上高难度事件          | 4-6人    |
| **处决科**     | 刺杀、猎杀、肃清、处决叛徒       | 3-5人    |
| **秘密保护科** | 间谍、高等级安保、审讯、消除影响 | 5-8人    |
| **占卜科**     | 预知、情报分析、命运干预评估     | 2-3人    |

> 第七层之后是第八层的1号记忆库。第七层充当了最后一道屏障的作用——任何未经授权者若想接近记忆库，必须首先突破第七层的防御。

### 三、各科室详细职能

#### 3.1 特别行动科

| 项目             | 内容                                |
| ---------------- | ----------------------------------- |
| **核心职能**     | 处理常规部门无法解决的III级以上事件 |
| **科室特点**     | 人员精干，行动自主权极高            |
| **出勤状态特权** | 一切行动无需经总部审批              |
| **当前科长**     | 刘思明                              |

特别行动科是裁判所处理最棘手问题的先锋力量。其科员通常具备独立完成高难度任务的能力，并可在出勤状态下行使不经过总部审批的特权。

#### 3.2 处决科

| 项目         | 内容                       |
| ------------ | -------------------------- |
| **核心职能** | 刺杀、猎杀、肃清、处决叛徒 |
| **科室特点** | 行动隐秘，直接执行最高指令 |
| **工作风格** | 非必要不说话，保持低存在感 |
| **当前科长** | 顾夕（代号"眼镜蛇"）       |

处决科是裁判所的"暗面"。其成员擅长追踪、隐匿与格杀，处理的对象通常是已被裁判所判定为"不可留"的目标——包括背叛裁判所的轮回者、无法控制的混沌造物，以及危害极大的敌对轮回者。处决科成员通常单独行动，或作为支援力量加入其他科室的任务。

> 处决科的"肃清"职能包括对内部叛徒的处置，因此其他科室对处决科成员往往保持一种微妙的距离感。

#### 3.3 秘密保护科

| 项目         | 内容                                       |
| ------------ | ------------------------------------------ |
| **核心职能** | 间谍活动、高等级安保、审讯、消除影响       |
| **科室特点** | 渗透与反渗透专家                           |
| **工作风格** | 深入敌方腹地，或隐藏在裁判所看不到的角落里 |
| **当前科长** | [待补充]                                   |

秘密保护科负责的是裁判所的情报网络与反间谍工作。其成员常以伪装身份渗透至其他组织内部，或负责保护裁判所的关键人物与设施。此外，该科室也负责对捕获的敌方人员进行审讯，以及对事件现场进行"清理"，即消除轮回者活动在普通人视野中留下的痕迹。

> 秘保科的"消除影响"职能，是维持轮回者世界与普通人世界之间屏障的关键环节。

#### 3.4 占卜科

| 项目         | 内容                         |
| ------------ | ---------------------------- |
| **核心职能** | 预知、情报分析、命运干预评估 |
| **科室特点** | 神出鬼没，不直接参与战斗     |
| **工作风格** | 只提供"答案"，不解释原因     |
| **当前科长** | [待补充]                     |

占卜科是第七层最神秘的科室。其成员专精于因果系与时间系符文，能够通过符文手段预判未来事件的发生概率、分析因果链的走向，以及评估命运干预可能产生的后果。占卜科不直接参与外勤任务，但其提供的"预判报告"往往决定了任务的优先级与行动方案。

> 占卜科的预测并非"绝对准确"，但准确率在65%以上——这个数字在混乱的轮回者世界中已经极其珍贵。
>
> 事实上，将占卜科放置于第七层更多是一种象征意义，而非实际需要。

### 四、职级体系

#### 4.1 职级层级

| 职级         | 职责                       | 权限                              |
| ------------ | -------------------------- | --------------------------------- |
| **所长**     | 裁判所最高决策者           | 全部权限                          |
| **副所长**   | 协助所长管理日常事务       | 全部权限（需所长授权）            |
| **分部长**   | 各地区分部负责人           | 辖区内III级以下权限               |
| **科室科长** | 各科室负责人               | 本科室内全部权限 + 跨科室协作权限 |
| **高级职员** | 资深轮回者，可独立执行任务 | II级以上行动权                    |
| **普通职员** | 执行常规任务               | I~II级行动权                      |
| **外勤人员** | 基础任务执行与支援         | I级行动权                         |
| **实习生**   | 在编人员的后备             | 受监督的行动权                    |

#### 4.2 第9层的特殊性

第9层为最高指挥层，所有V级指令均由其发出。该层极少有人进出——实际上，进入第9层的人员屈指可数，且每次有人进入都会伴随V级行动命令的下达。

> 老所长据称就在第9层办公。但关于老所长的具体信息，即使在科长级别中也是高度机密。

## 🔴 深层设定

### 一、轮回与识觉抑制：世界的底层真相

#### 1.1 三大纪元

从上帝视角来看，本世界的文明活动可划分为三个纪元：

| 纪元         | 时期              | 特征                                                                                       |
| ------------ | ----------------- | ------------------------------------------------------------------------------------------ |
| **余烬纪元** | 远古              | 创造了基耶夏韦的文明。虽非人类形态，但具有高度的符文技术能力                               |
| **无瑕纪元** | 海德里斯/卡曼时期 | 人类文明首次繁盛。海德里斯人关闭了基耶夏韦的识觉抑制功能，导致文明加速灭亡，审判日首次降临 |
| **新芽纪元** | 当前时期          | 审判日之后重新崛起的文明。识觉抑制功能重新生效，为当前文明争取了时间                       |

> 当前纪元的轮回者组织中，仅有极少数高层知晓这三个纪元的完整存在。

#### 1.2 基耶夏韦（轮回巨构）

**基耶夏韦**（Kijexawe）——海德里斯语中意为"轮回之地"或"轮回之境"——是一个悬浮在地心深处的**巨大黑色正八面体结构**。它由余烬纪元的智慧种族（简称"余烬人"）建造，是目前已知的轮回与灵魂转世机制的核心。

> 在当前的日常用语中，"轮回之境"一般用于指代基耶夏韦联通的空间，而该建筑本身被称为"轮回巨构"或直接称"基耶夏韦"。

#### 1.3 基耶夏韦的功能

基耶夏韦同时执行三项核心功能：

1. **识觉抑制**：该结构每时每刻向外辐射一种能量，抑制智慧生物的识觉觉醒。只有愿力水平（脑波强度）突破阈值的人才能完成觉醒成为轮回者。这一功能客观上极大地延缓了审判日的到来。

2. **灵魂记录**：对所有完成了轮回者觉醒的智慧生物进行记录。当灵魂脱离身体（死亡）时，该灵魂会受到基耶夏韦的"呼唤"。

3. **轮回转世**：被呼唤的灵魂坠入地心深处，基耶夏韦将其绝大多数记忆转化为愿力以供给自身运行，将重新变得纯净的灵魂送入新生儿体内，取代其原本将要诞生的灵魂降生。

> 极为罕见的，有些人在灵魂尚未离体时就能感受到基耶夏韦的呼唤，在掌握方法后可以"肉身踏入"基耶夏韦。

#### 1.4 无瑕纪元的覆灭

无瑕纪元时，出于卡曼人的入侵压力和对文明跃升的渴望，海德里斯人通过技术手段**关闭了基耶夏韦的识觉抑制功能**。此举使海德里斯迎来了空前繁盛，但代价是文明灭亡的极大加速。当审判日首次降临时，海德里斯人完全不知道发生了什么。

这一历史教训，正是当前纪元轮回者组织如此重视"维持识觉抑制"的根本原因。

#### 1.5 余烬人的目的

余烬人为基耶夏韦设计了识觉抑制功能，但其目的已无从考证。其文明的创造者——余烬人——已经在漫长的历史中湮灭，他们的真实动机成为永恒的谜团。

唯一可以确认的是：**识觉抑制并非自然规律，而是被设计出来的系统**，其存在使当前纪元的人类文明得以延续至今。

### 二、第9层的真实情况

> **建议揭示时机**：当玩家角色晋升至科长级，或触发与"所长"相关的剧情时。

#### 2.1 "老所长"的真相

第9层的"老所长"是真实存在的，但其生命状态与常人不同。事实上，老所长的生命已在多年前的某次事件中终结，但裁判所参考了海德里斯的永生者相关技术使其意识得以留存，以非实体的形式继续履行所长职责。

> 这意味着，所有从第9层发出的指令，其实来自一个"早已死去的人"。

#### 2.2 第9层的访问记录

在裁判所的历史档案中，进入第9层的人物屈指可数。但有一个被档案刻意模糊的事实：**每一次V级指令的下达，都伴随着一次"灵魂共鸣"事件**，即第9层对第7层或第8层的某种定向意识传输。

这种传输的接收者，通常是第7层各科室的科长。

### 三、裁判所的控制手段

#### 3.1 记忆删除

裁判所拥有对普通人进行**选择性记忆删除**的技术手段。当普通人类无意中接触轮回者活动时，裁判所会通过符文技术消除其相关记忆。

> 这种操作通常由秘密保护科执行，且有一套标准化的操作流程。

#### 3.2 记忆档案分级管控

第8层（1号记忆库）中存放着海量的记忆体档案。这些档案并非全部真实，部分档案经过人为修饰或选择性编辑，以控制信息流向特定人员。

| 记忆体等级 | 真实度                     |
| ---------- | -------------------------- |
| I~II       | 完全真实，用于常规任务     |
| III        | 部分修饰，删除了敏感信息   |
| IV~V       | 高度管控，仅特定权限者可见 |

#### 3.3 轮回者监控

裁判所对管辖范围内的轮回者保持**持续监控**，但监控的强度并非均等。大部分轮回者仅被记录基本信息；只有Ⅲ级及以上能力者才被建立完整的个人档案。

> 每一位科长级的轮回者，在第8层都有一个独立的记忆档案库。

### 四、组织内部的派系

> **建议揭示时机**：当玩家涉足裁判所内部政治或深层冲突时。

梦境裁判所并非铁板一块。在表面统一的组织结构之下，存在若干**非正式的派系**：

| 派系       | 倾向                                     |
| ---------- | ---------------------------------------- |
| **激进派** | 倾向主动出击，先发制人                   |
| **保守派** | 倾向保守行动，维持现状                   |
| **学术派** | 倾向研究而非行动，重视符文理论与纪元历史 |
| **行动派** | 倾向实地解决，以实战为导向               |

> 这些派系之间并非敌对关系，但在重大决策上存在分歧。

#### 4.1 关于基耶夏韦的信息管控

裁判所高层对基耶夏韦的存在及其功能有严格的信息管控。在轮回者内部，关于"地心巨构"的说法流传甚广，但绝大多数人将其视为一种传说或简化解释，而非一个真实存在且仍在运行的空间实体。

> 裁判所的官方立场是：轮回是"自然规律"的一部分。对基耶夏韦真实性的揭露，通常只在轮回者晋升至科长级或接触V级档案时才会发生。

### 五、裁判所与其它组织的关系

#### 5.1 与蔷薇学会的关系

裁判所与蔷薇学会保持**正式合作关系**。蔷薇学会提供符文理论研究的支持，裁判所则为蔷薇学会提供考古与实地调查的安全保障。

> 但这种合作关系并非完全透明。蔷薇学会掌握着某些裁判所不知晓的古代符文知识，尤其是涉及海德里斯与无瑕纪元的部分。

#### 5.2 与混沌导引学派的关系

混沌导引学派与裁判所的关系更为复杂。该学派专注于混沌研究，但其行事方式较为隐秘，且部分成员与裁判所的非正式派系存在联系。

> 裁判所官方对混沌导引学派保持距离，但在必要时会寻求其技术支持，尤其是在处理大规模混沌污染时。
