# 蔷薇学会组织详章/符文解构学

## 🟢 基础设定

### 一、组织总述

#### 1.1 定位与职能

**蔷薇学会**是世界上最重要的符文研究组织之一，其核心研究方向是**符文解构学**——一门专注于安全解除、干扰和破坏已有符文术式的学科。

学会的前身为炼金术士行会，经过数百年的演变，现已成为集学术研究、实战应用与组织自保能力于一体的综合性组织。蔷薇学会与梦境裁判所保持正式合作关系，裁判所提供安全保障与实地调查支持，学会则提供符文理论研究的成果。

#### 1.2 管辖范围与总部

蔷薇学会在全球范围内设有多个分会，其总会位于**密克罗林**（Microlin）的首都**密克罗林城**。

学会采用**扁平化架构**，每个地区的分会均有相对独立的自我管辖权。这种结构使其在全球范围内保持了高度的适应性与灵活性。

#### 1.3 组织标志

蔷薇学会的标志通常为**蔷薇花**与**解构符文**的结合图案，象征着学会"在美丽中瓦解威胁"的理念。具体形态因分会不同而有细微差异。

### 二、历史沿革

#### 2.1 起源：炼金术时代

符文解构学最早脱胎于炼金术鼎盛的时期。炼金术往往需要大量的符文阵法支持，一次构造错误就可能造成极大的资源浪费甚至人员伤亡。因此，一小部分炼金术士开始研究"不用激发已构造的符文术式便能安全解除符文构造"的方法。这便是符文解构学的早期雏形。

这一时期的技术尚不稳定，解构手段也远未达到"实战可用"的程度。

#### 2.2 转折：斯图尔特·史密斯与《符文解构概论》

**17世纪末**，时任蔷薇学会会长**斯图尔特·史密斯**（Stewart Smith）在前人研究的基础上，完成了一部划时代的著作——《符文解构概论》。

此书不仅系统化了符文解构的理论框架，更提出了将解构技术应用于实战的可行性方案。自此：

- 符文解构学**正式脱离**符文阵法学，成为一门独立的学科
- 轮回者战斗职业在原有的七大分类之外，新增了第八种：**解构师**

> 斯图尔特·史密斯因此被后世尊为"符文解构学之父"。

#### 2.3 发展：解构师的诞生

在《符文解构概论》问世后，蔷薇学会致力于开发符文解构学的实际应用，最终将解构真正应用于实战之中。

**解构师**这一战斗职业由此诞生。解构师通常具有较强的近身战斗能力，其核心战术为：

1. **先解构**——瓦解对方即将发动或正在维持的符文术式
2. **再打击**——以非符文手段（体术、武器等）施以强力攻击

#### 2.4 关于解构符文的学术争论

解构师所掌握的符文体系独立于其它系谱，被称为**解构符文**。

一个长期的学术争议在于：解构符文是否属于真正的"符文"？反对者认为大多数解构符文单独使用时没有任何效果，只对特定类型的符文起到干扰和破坏作用，这不符合"符文是客观术式单元"的定义。

这场争论持续了数百年，直到**解构系奇迹——「定界幻灭」的现世**才终结了讨论。奇迹的出现证明了"解构"本身就是一个独立的符文系谱，而非阵法学的一个分支。

> 蔷薇学会目前仍保有关于"定界幻灭"的部分研究记录，但其具体持有人的身份仅限学会高层知晓。

### 三、内部架构

#### 3.1 会员分类

蔷薇学会采用分级会员制度，不同类型会员的权力与义务各不相同：

| 身份               | 描述               | 职责/权限                                      |
| ------------------ | ------------------ | ---------------------------------------------- |
| **会长**           | 学会最高领导人     | 统筹学会整体发展方向与重大决策                 |
| **分会长**         | 各地区分会负责人   | 在各自分会内部拥有最高话语权                   |
| **董事**           | 董事会成员         | 参与最高决策，由会长、分会长及部分高级会员组成 |
| **高级会员**       | 对学会有重大贡献者 | 享有更高信息权限与研究资源                     |
| **正式会员**       | 已通过考察期       | 受学会规则约束，享有会员权益                   |
| **临时会员**       | 考察期中           | 考察期通过后自动转为正式会员                   |
| **非正式自由会员** | 有特殊协议的合作者 | 为学会做事或以学会名义活动，但不受学会规则约束 |

#### 3.2 董事会

董事会是蔷薇学会的**最高权力机关**，由以下成员组成：

- 现任会长（董事会主席）
- 各分会分会长
- 部分高级会员（由董事会选举产生）

董事会负责决定学会的重大研究方向、资源分配与对外策略。

#### 3.3 扁平化结构

蔷薇学会不设臃肿的中间管理层，各分会拥有高度自治权。总会对分会的管控主要体现在：

1. **研究方向引导**（通过董事会决议）
2. **重大资源分配**（如经费、稀有符文资料）
3. **会员资格的审批与撤销**

这种结构使学会在面对突发情况时反应迅速，且能根据不同地区的具体需求灵活调整工作重点。

### 四、与其它组织的关系

#### 4.1 与梦境裁判所

蔷薇学会与梦境裁判所为**正式合作关系**：

- 学会提供符文理论与符文解构学的技术支持
- 裁判所提供实地调查、安全保卫与行动支持

> 在这种关系中，学会倾向于"提供答案"，裁判所倾向于"执行行动"。双方在各自擅长的领域互补。

#### 4.2 与其他组织

蔷薇学会与**混沌导引学派**的关系较为疏远。两个组织虽然都从事符文相关研究，但研究路径截然不同。学会专注于"解构"，学派专注于"混沌"。双方偶有信息交换，但不存在正式合作关系。

### 五、重要地点

#### 5.1 总会·密克罗林城

蔷薇学会的总会位于密克罗林首都**密克罗林城**的旧城区。建筑本身为一栋具有数百年历史的花岗岩建筑，表面爬满了真正的蔷薇藤蔓——这既是装饰，也是一种符文预警系统。

> 总会内部保存着大量古代符文文献与解构符文的研究记录，包括斯图尔特·史密斯的手稿原件。

#### 5.2 主要分会

蔷薇学会在以下地区设有分会（非完整列表）：

- 欧洲
- 东亚（与梦境裁判所合作密切）
- 北美（独立运作）
- 南亚（分支较小）

## 🔴 深层设定

### 一、蔷薇学会的真正起源

> **建议揭示时机**：当玩家深入接触学会核心圈层，或涉及斯图尔特·史密斯时代的历史时。

#### 1.1 炼金术之前的渊源

公开历史中，蔷薇学会的起源被追溯至炼金术时代。但学会内部的核心档案显示，其组织的真正根源可以追溯到**无瑕纪元末期**。当时一批海德里斯学者预见到文明即将覆灭，便将部分符文知识以加密形式埋藏在后世能够发掘的位置。

蔷薇学会的前身，正是**发现了这批遗产的炼金术士们**。他们在此后数百年间逐步破译并吸收了这些知识，最终形成了符文解构学的理论体系。

> 这意味着，蔷薇学会的核心知识并非完全源自"独立研究"，而是**无瑕纪元遗产的延续**。这一事实即使在学会内部，也只有董事级别成员知晓。

#### 1.2 与海德里斯的隐含关联

基于上述历史，蔷薇学会（特别是其高层）与海德里斯抗争派之间存在一种**间接的传承关系**。学会研究的许多理论框架，其底层逻辑与海德里斯符文体系高度吻合，但学会对此进行了独立发展，并未完全遵循海德里斯的原始方案。

> 这种继承关系并非所有海德里斯派系都认可。复乐园对蔷薇学会的态度就较为复杂——有时视为"知识保管者"，有时视为"窃取了不该属于他们的知识的人"。

### 二、"定界幻灭"与亚伯拉罕·史密斯

> **建议揭示时机**：当玩家接触到解构系奇迹相关剧情，或与亚伯拉罕·史密斯本人交互时。

#### 2.1 奇迹的传承

「定界幻灭」作为解构系奇迹，其持有者始终是蔷薇学会的会长。这一传承模式并非偶然——该奇迹的继承方式本身就与学会的"会长传承仪式"高度耦合。

任何试图继承会长之位的人，必须首先通过**奇迹共鸣测试**，即验证其灵魂与「定界幻灭」的匹配程度。若测试失败，其将无法成为正式会长（但可能以其他身份留在学会中）。

> 这意味着"蔷薇学会会长"这一职位，在某种意义上是被奇迹"选择"的。

#### 2.2 亚伯拉罕·史密斯的能力边界

亚伯拉罕·史密斯是当代最强的解构师，但「定界幻灭」的使用存在明显限制：

- **空间闪烁模式**（绝对成立干涉）每次使用后需长时间恢复
- **伪领域模式**的效果随距离递减，有效范围有限
- 该奇迹对**时间系、空间系、因果系**符文的效果较弱（相克关系）

> 因此，亚伯拉罕·史密斯通常不会主动卷入大规模战斗，他的价值在于"关键时刻一击定局"，而非持续作战。

#### 2.3 会长与"史密斯"姓氏

"史密斯"这一姓氏在蔷薇学会会长序列中反复出现。斯图尔特·史密斯与亚伯拉罕·史密斯相隔数百年，但均为学会会长。

这是一种巧合，还是某种刻意的安排？学会内部的档案对此保持沉默。

> GM可决定：史密斯家族是否与海德里斯遗产的首次发现者有关联，或是「定界幻灭」本身对"特定血脉"的偏好造成的。

### 三、解构师的真实局限性

> **建议揭示时机**：当玩家首次遭遇解构师对手，或考虑扮演解构师角色时。

#### 3.1 解构并非万能的

尽管解构师在对阵符文使用者时具有明显优势，但其局限性同样明显：

- **对无符文目标无效**：解构系符文在应对纯粹物理威胁时几乎无用
- **对多重符文同时维持者有压力限制**：一个解构师同时瓦解的符文数量受算力限制，面对"百符齐发"时可能捉襟见肘
- **近身作战要求高**：大多数解构师需要较强的体魄或武器熟练度，因为解构本身不直接造成伤害

#### 3.2 解构师的培养成本

培养一名合格的解构师极为困难：

- 需要同时学习**符文阵法学**（理解目标结构）和**解构学**（瓦解目标结构）
- 需要大量实战练习，但练习对象必须是真实的符文术式，风险较高
- 解构符文的观想方式与常规符文不同，初学者极易产生"认知混乱"

> 因此，蔷薇学会虽然掌握解构技术，但其解构师数量始终有限。

### 四、学会的秘密研究

> **建议揭示时机**：当玩家进入学会核心区域或接触高级别机密档案时。

#### 4.1 对"余烬纪元"的研究

蔷薇学会对余烬纪元（基耶夏韦的建造者）的研究程度远超梦境裁判所的认知。学会手中掌握着若干**余烬纪元遗留的符文碎片**，其结构与当前所有系谱均不兼容。

学会的目标之一，是**破译余烬纪元的符文体系**。如果成功，可能揭示识觉抑制的深层机制，甚至可能找到手动调节识觉抑制强度的方法。

> 这一研究若被复乐园获知，可能会带来严重后果。

#### 4.2 解构符文的"自体化"研究

虽然解构系已经被证明为一种独立的系谱，但是现有的记录中从未观察到以解构符文为灵魂记忆的轮回者。学会正在研究一种可能性：将解构符文与轮回者的**灵魂印记**结合，使解构能力成为"本能反应"而非"主动施放"。

若此研究成功，将彻底改变解构师的战斗方式——无需提前准备即可自动瓦解来袭的符文攻击。但这同时可能导致轮回者的灵魂印记受到不可逆的改造，风险极高。

> 这一研究目前处于理论阶段，尚未进行人体实验。
