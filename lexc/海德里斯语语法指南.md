# 海德里斯语语法指南

海德里斯语是一种**分析语**（或称**孤立语**），其语法与汉语高度类似，**没有屈折变化（动词无人称/时态变位，名词无性数格变化），语序固定，依靠虚词和语序表达语法关系**。

---

## 一、语音与书写（详见发音指南）

- **音节结构**：`CV(N)` —— 每个音节必须以辅音开头，以元音或鼻音结尾。
- **重音**：一般落在第一个音节上。
- **书写**：从左到右，单词之间用空格分割，句子之间用标点符号分割。

---

## 二、词类概述

海德里斯语的词类包括：

| 词类 | 示例 | 说明 |
|------|------|------|
| 名词 | `re` (人), `hy` (太阳) | 无单复数变化，如需复数加后缀`si` |
| 动词 | `jo` (吃), `mu` (移动) | 无时态人称变位 |
| 形容词 | `dae` (大), `wau` (好) | 可直接作谓语（`thae wau` 他好） |
| 数词 | `wi` (一), `tae` (十) | 单独使用或修饰名词 |
| 代词 | `la` (我), `thae` (他) | 人称、指示、疑问 |
| 副词 | `ji` (不), `hu` (快) | 修饰动词或形容词 |
| 助词 | `de` (的), `dau` (使动) | 无实义，表达语法关系 |
| 连词 | `nan` (和), `chu` (因为) | 连接词、短语或分句 |
| 介词 | `zy` (在), `doi` (向) | 表方位、时间、方向等 |
| 转义词 | `ha`, `ki` 等 | 无实义，组合时改变邻近词义 |

---

## 三、基本语序

**核心语序：SVO（主语-谓语-宾语）**

- `la jo jota.` → 我 吃 食物 → 我吃饭。
- `thae lu mi.` → 他 看 你 → 他看你。

**不允许倒装、定语后置、状语后置。** 所有修饰成分必须放在被修饰词之前（详见第八节）。

---

## 四、动词的时态、体、情态

### 4.1 时态助词（置于动词之前）

| 助词 | 功能 | 例句 |
|------|------|------|
| `fe` | 现在 / 正在进行 | `thae fe jo.` 他正在吃 |
| `zu` | 过去 / 已完成| `thae zu jo.` 他吃了 |
| `mae` | 将来 | `thae mae jo.` 他将要吃 |

**经验体**：`zu ... ge` 结构  

- `la zu jo jota ge.` 我吃过饭。

**持续体**：`fe ... zy` 结构  

- `thae fe jo zy.` 他吃着呢。  

### 4.2 情态动词

情态动词直接放在动词前使用。

| 词 | 意义 | 例句 |
|----|------|------|
| `jang` | 可以、能、允许 | `mi jang gi.` 你可以走。 |
| `pe` | 希望、想、需要 | `la pe jo.` 我想吃。 |
| `daepe` | 必须、应该 | `mi daepe zi.` 你必须睡。 |
| `maeno` | 可能、也许 | `thae maeno gi.` 他可能去。 |

### 4.3 否定

否定副词 `ji` 放在被否定的成分（动词、形容词、情态词）之前。

- `la ji no.` 我不知道。
- `thae ji wau.` 他不好。
- `mi ji jang gi.` 你不可以走。

> “没有”（存在否定）用 `ji ge`：`dhei rei ji ge ja.` 房子里没有猫。

---

## 五、疑问句

### 5.1 是非问句

在陈述句末尾加疑问助词 `joi`。

- `mi wau joi?` 你好吗？
- `thae zu jo jota joi?` 他吃了饭吗？

### 5.2 特指问句

疑问代词留在原位，不提前。

| 疑问代词 | 意义 | 例句 |
|----------|------|------|
| `se` | 什么 | `mi jo se?` 你吃什么？ |
| `sere` | 谁 | `sere 「la」?` 谁是“我”？ |
| `sewe` | 哪里 | `mi gi sewe?` 你去哪里？ |
| `seli` | 什么时候 | `thae seli kae?` 他什么时候回来？ |
| `sewi` | 哪个 | `mi pe sewi?` 你想要哪个？ |
| `sechu` | 为什么 | `mi sechu ky?` 你为什么哭？ |

---

## 六、被动句与使动句

### 6.1 被动句

**结构**：受事 + `roi` + 动词 + （`tei`/`doi` + 施事者）

- `thae roi du.` 他被恨。
- `la roi du tei mi.` 我被你恨。  

### 6.2 使动句

**结构**：施事 + `dau` + 受事 + 动词

- `la dau hafeita habeng.` 我把衣服脱了。
- `thae dau la zi.` 他让我睡。

---

## 七、比较句

比较助词 `shei` 置于形容词之前，表示“比”。

**结构**：主语 + `shei` + 形容词 + 比较对象

- `thae shei tong la.` 他比我高。
- `jota shei ny can.` 食物比水甜。

> 程度副词 `sen`（甚至、更）可加强比较：`thae shei sen tong la.` 他比我更高。

---

## 八、定语与状语

### 8.1 定语

所有定语（形容词、名词、代词、短语）**必须放在名词前面**。  
当有多个定语时，**只在最后一个定语后加助词 `de`**。

- `wi kican fo de hafeita` → 一件 湿 白 的 衣服  
- `la de shi` → 我的名字

> 前例也可写作 `wi kican de fohafeita` ，原因详见12.2黏着现象

### 8.2 状语

与定语同理：所有状语必须放在动词之前，多个状语时**只在最后一个后加 `de`**。

- `thae hu de mu.` 他快速地跑。
- `la fe zy kiwe de jo.` 我正在这里吃。（`fe`时态词，`zy kiwe`地点状语）

---

## 九、连动结构

按时间或逻辑顺序排列动词，中间不加连词。

- `la gi dhei jo jota.` 我回家吃饭。 （先“去家”，再“吃饭”）
- `thae zu luso run thi.` 他读了符文思考。 （先“读”，后“思考”）

---

## 十、存现句

**结构**：处所 + `zy`/`kiwe` + `ge` + 存在物

- `dhei zy ge wi ja.` 房子里有一只猫。
- `tho jva kiwe ge dha can.` 石头下面有很多水。

> 存在否定用 `ji ge`：`rei zy ji ge re.` 里面没有人。

---

## 十一、数量表达

### 11.1 数词系统

| 1-10 | 百 | 千 | 万 | 亿 |
|------|----|----|----|----|
| `wi` 一 | `ho` 百 | `qe` 千 | `dhu` 万 | `pei` 亿 |
| `je` 二 | | | | |
| `sa` 三 | | | | |
| `xvu` 四 | | | | |
| `me` 五 | | | | |
| `lae` 六 | | | | |
| `ve` 七 | | | | |
| `ba` 八 | | | | |
| `ga` 九 | | | | |
| `tae` 十 | | | | |

**多位数的构成**：

- 11：`tae wi`（十 一）
- 20：`je tae`（二 十）——注意与汉语顺序相同（十位在前）
- 123：`wi ho je tae sa`（一百 二 十 三）——百、十直接连接
- 1005：`wi ho noi me`（一百 零 五）——`noi`（零）用在中间

### 11.2 数量与名词

数词直接修饰名词，不加量词。

- `sa re` 三个人
- `wi ja` 一只猫

如需表“一个”可省略数词，用单数形式。

### 11.3 分数与倍数

- 一半：`vau`
- 倍数：用 `shanei`（乘）表达：`sa shanei wi` 三倍
- 分数：用 `shunei`（除）表达：`vau jy wi shunei je` 一半是二分之一

## 十二、复合词与黏着现象

### 12.1 转义词

`ha`, `nei`, `ki`, `thu`, `vy`, `ze` 等本身无实义，与其它音节结合时改变词义。  
例如：`ha` + `ci`（空气）→ `haci`（空的）；  
`vy` + `so`（说）→ `vyso`（写）——转义词改变了动词的语义域。

### 12.2 黏着现象

黏着现象是指**在特定条件下，修饰语与被修饰词合并为一个词**的现象。黏着后形成的**黏着词**在语法上被视为一个完整的词汇单元，充当原本被修饰词的角色。因此，**助词 `de` 只能提前到黏着成分之前，而不能省略**。

黏着现象分为两类：**色彩黏着**和**固定搭配**。

---

#### 12.2.1 色彩黏着

当修饰语**包含颜色词**（如 `fo` 白、`hi` 黑、`rae` 红、`bu` 蓝等）时，可以将颜色词与被修饰的名词直接黏着，同时将助词 `de` 提前到颜色词之前。如果修饰语**只有颜色词**，则省略 `de` 。

**规则**：`[其他定语] + de + [颜色词 + 名词]`

**示例**：

> 原句（常规多重定语）：  
> `wi kican fo de hafeita` → 一件 湿的 白的 衣服  
> （最后一个定语 `fo` 后加 `de`）

> 色彩黏着写法：  
> `wi kican de fohafeita` → 一件 湿的 的 白衣服  
> （`fo` 与 `hafeita` 黏合成 `fohafeita`，`de` 提前到其前）

两种写法**语法上均正确**，后者更口语化，且强调颜色与物体的整体性。

**注意**：如果还有其他定语（如数量、状态），它们仍按正常规则处理，只有颜色部分参与黏着。

---

#### 12.2.2 固定搭配

某些高频修饰关系已经**彻底固化**为一个独立词汇，不再能拆解为“修饰语 + `de` + 名词”。这类黏着词已收录在词典中，使用时直接当作普通名词即可。

**示例**：
- `kare`（月球人） ← `ka`（月） + `de` + `re`（人）

**规则**：
- 固定黏着词不可再插入 `de` 或拆分。
- 当它们被其他定语修饰时，新定语按正常规则加 `de` 置于其前：
  - `wi xing de kare` → 一个愚蠢的 卡曼人（正确）
  - ~~`wi xing kare`~~（错误，缺少 `de`）

## 十三、感叹词

感叹词用于表达强烈的情感（请求、惊讶、赞美、痛苦、呼唤等），通常独立于句子的语法结构之外。

海德里斯语有一个专用的感叹助词 **`nau`**，其用法**类似于“请”但带有更强的感叹语气**，常用于祈求、迫切请求或引人注意的呼唤。

### 13.1 `nau` 的基本用法

`nau` 可置于**句首**或**句尾**，表达说话人强烈的情感或请求。

- **句首**：强调感叹本身，类似于“啊！请……”、“拜托……”
- **句尾**：追加感叹语气，类似于“……啊！”、“……吧！”

**示例**：

> `nau, mi dau la gi!`  
> 啊，请你让我去！  
> （强烈的请求，近乎祈求）

> `go zi, nau!`  
> 请睡吧，拜托了！  
> （句尾 `nau` 加深请求的迫切感）

> `nau, wae jy se?`  
> 哎呀，这是什么？  
> （表达惊讶或疑惑，类似“啊？”）

### 13.2 与敬语助词 `go` 的区别

| 词 | 位置 | 语气强度 | 典型场景 |
|----|------|----------|----------|
| `go` | 动词前 | 礼貌、中性 | 日常请求：“请坐” `go wy` |
| `nau` | 句首或句尾 | 强烈、感叹、祈求 | 紧急求助、痛苦呼吁、惊喜赞叹 |

**对比**：

- `go tei la wi lvu.` → 请给我一块钱。（普通礼貌）
- `nau, tei la wi lvu!` → 啊，给我一块钱吧！（迫切、或许带抱怨）

## 十四、特殊句式示例

### 14.1 连动 + 使动复合

`la dau thae zi.` 我让他睡。

### 14.2 条件句（如果……那么……）

- 如果：`nvu`（假设）  
- 那么：`dauli`（所以）  

`nvu hy zu ca mu, dauli la mae hazu.`  
如果太阳升起来了，那么我就醒来。

### 14.3 因果句（因为……所以……）

- 因为：`chu`  
- 所以：`dauli`

`chu la zu jo dha, dauli la fe ty.`  
因为我吃得多，所以我累了。

### 14.4 让步句（虽然……但是……）

- 虽然：`thumoi`  
- 但是：`hauli`

`thumoi thae nae, hauli thae ke dae.`  
虽然他小，但是力气大。
